# Tools

Dieses Verzeichnis enthält eigene Bash-Skripte zur Verwaltung der Infrastruktur.

## compose-manager.sh

Startet oder stoppt alle Docker-Compose-Projekte.

## docker-status.sh

Zeigt Anzahl laufender Container.

## healthcheck.sh

Prüft HTTP-Endpunkte und Datenbanken.

## backup-manager.sh

Erstellt Backups.

## restore-manager.sh

Stellt Backups wieder her.

## system-report.sh

Erstellt Infrastrukturberichte.
